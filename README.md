# 📝 To-Do List

A modern, clean, and intuitive **To-Do List application** designed to help users organize their daily tasks, track progress, and stay productive.

The project focuses on simplicity, usability, and a responsive user experience while providing the essential tools needed for effective task management.

---

## ✨ Features

* ➕ **Add Tasks** — Create new tasks quickly and easily.
* ✏️ **Edit Tasks** — Update task details whenever needed.
* ✅ **Complete Tasks** — Mark tasks as completed when finished.
* 🗑️ **Delete Tasks** — Remove tasks you no longer need.
* 📋 **Task Management** — Keep all your tasks organized in one place.
* 📱 **Responsive Design** — Works across desktop, tablet, and mobile devices.
* 🎨 **Clean & Modern UI** — Simple interface focused on usability.
* ⚡ **Fast & Lightweight** — Designed for a smooth and efficient experience.
